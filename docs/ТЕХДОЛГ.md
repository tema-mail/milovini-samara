# Техдолг

- Отправка заказов и заявок в приёмник Тильды (`src/lib/forms.ts`) реализована, но живой заявкой не проверена – тестовый заказ ушёл бы флористу. Проверить одним реальным заказом с пометкой «ТЕСТ» по согласованию с владельцем. Риск: приёмник может не принять запрос с чужого домена (no-cors, ответ не читается).
- Нет sitemap.xml и robots.txt для боевого домена – добавить при переезде на milovinisamara.ru (сейчас копия на Pages закрыта noindex).
- Онлайн-оплаты нет: на Тильде оплата шла после подтверждения флористом, у нас так же (ссылка/QR, карта, наличные).
- Товары сняты 13.10.2026; при изменениях в Тильде – `npm run data` и пересборка. Своей админки товаров нет.
- Заявки в кабинете – пример: формы сайта шлют в приёмник Тильды, свой приёмник (как TEYES leads.py) не подключён.
- Метрика клона не подключена (счётчик 112714809 стоит только на живом milovinisamara.ru); Search Console – сервисный аккаунт не добавлен в ресурс клиента; Вебмастер API недоступен по сети.
- Новый раздел из админки появляется фильтром в общем каталоге, но своей страницы-каталога (как /catalog/byket) не получает – их список в src/lib/site.ts (CATALOGS).
- Кабинет покупателя – демо в браузере (путь А, docs/ПЛАН-ЛК.md): баллы не настоящие и живут в одном браузере, письмо с кодом не уходит. Для боя – путь Б: заказы и баллы на сервере shop-modules (S7), рассылка кодов, сайт на своём домене рядом с API; реализация `ShopApi` через запросы вместо `createDemoShop`.
- Скидку 20% на первый заказ даёт флорист вручную; движок кабинета её не знает – начисление считается от суммы корзины без скидки. В пути Б – акцией модуля промокодов shop-modules, тогда начисление пойдёт от суммы после скидки.
- Галочка «Согласен на обработку персональных данных» на оформлении (`src/islands/Order.tsx`, `agree` = true) стоит заранее – стандарт владельца: пустая (найдено 19.10 при работе над кабинетом, не правилось – не в задаче).
- Движок кабинета обновляется копией из shop-modules (`npm run build:sdk` → `src/vendor/shop-engine/`, SOURCE – коммит); автоматической сверки версии нет.
