# Milovini Flowers (Самара) – перенос с Тильды на код

Сайт цветочного магазина milovinisamara.ru (Тильда, клиентский) на Astro + Preact.
Замысел и границы – `docs/ЗАМЫСЕЛ.md`, решения – `docs/РЕШЕНИЯ.md`, долги – `docs/ТЕХДОЛГ.md`.

## Стек и запуск
- Astro 7 (статическая сборка), острова Preact, общее состояние – `@preact/signals` (`src/lib/store.ts`).
- `npm run dev` – разработка, `npm run build` – сборка в `dist/`.
- `npm run data` – заново снять товары/разделы/акции с живого сайта (store.tildaapi.com) в `src/data/*.json`
  и картинки в `public/img/p`. `npm run data -- --img` – скачать картинки страниц: любые ссылки
  `https://static.tildacdn.com/...` в `src/` превращаются в локальные через `src/lib/img.ts`.
- Публикация: GitHub Pages (`tema-mail/milovini-samara`), workflow `.github/workflows/pages.yml`.

## Структура
- `src/pages` – маршруты повторяют адреса оригинала (`/catalog/byket`, `/catalog/tproduct/<id>-<slug>`, `/tpost/...`).
- `src/components` – секции страниц (.astro), `src/islands` – интерактив (корзина, избранное, меню, квиз, заказ).
- `src/data` – снятые данные; правки текстов страниц – в самих страницах.

## Соглашения
- Тире только короткое «–», длинное (U+2014) не ставить нигде.
- Каталог: на телефоне две карточки в ряд, с 1024px – три/четыре; фильтр – чип «Все» первым, выбор прячет лишнее.
- Скрытие через `hidden` страховать `[hidden]{display:none!important}`.
- Внутренние ссылки и картинки – только через `u()` из `src/lib/url.ts` (подпапка Pages задаётся `PUBLIC_BASE`).

## Правила работы
- Файл больше 800 строк не дописывать, а выносить новый модуль.
- Делать только то, о чём просили. Никаких попутных улучшений и лишних файлов.
- После каждого рабочего шага – коммит.
- Перед правкой прочитать те места, которых она касается, а не догадываться.
- Задача трогает больше трёх файлов кода – остановиться и предложить разбить.
- Чего не знаешь – спросить, а не подставить заглушку и не выдумать.
- Решение, записанное только в комментарии, не считается внедрённым: выбор
  модели, провайдера или настройки живёт в константе, которую код читает.
- Владелец сообщает о сбоях словами в чате и в файлы сам не пишет –
  записывать за ним.
- После задачи – строка в `docs/РЕШЕНИЯ.md`, найденный долг – в `docs/ТЕХДОЛГ.md`.
